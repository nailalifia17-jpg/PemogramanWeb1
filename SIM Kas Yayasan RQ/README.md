# SIM Kas Yayasan RQ

Fondasi Jobsheet 1-4 untuk aplikasi pencatatan keuangan Yayasan Rumah Quran. Tahap ini berisi struktur HTML, Bootstrap, navigasi hamburger, rancangan UI, dan form statis sebelum pemrosesan PHP/database.

Fitur rancangan: pemasukan, pengeluaran, kategori transaksi, keterangan, laporan, serta identitas visual Yayasan Rumah Quran.
